# Contributing to hello-world-na2024

This repository exists to practice the GitHub Flow: branch, commit, pull
request, merge. It follows the same **PR-based flow** as every other repo —
no direct pushes to `main`, every change through a draft PR.

## Workflow

1. **Branch** off `main`:
   ```bash
   git checkout -b <short-description>
   ```
2. **Commit** small, focused commits.
3. **Open a draft PR** against `main`. There is no CI gate here — the review
   and the flow itself are the practice.
4. **Owner merges.** Merge commits reference the PR number.
5. **No direct pushes to `main`.** Ever.

## Changelog

Each PR adds a line under `## [Unreleased]` in `CHANGELOG.md`.
